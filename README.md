# Santiago's Clean

Site de uma página da Santiago's Clean, lavagem a seco e higienização de estofados em Lavras – MG e região.

- `index.html`: conteúdo
- `css/main.css`: visual
- `js/main.js`: animações (GSAP, ScrollTrigger, SplitText e Lenis, em `assets/vendor/`)
- `assets/media/`: fotos e vídeos curtos tirados dos vídeos do Instagram @santiagosclean2026

Publicado pelo GitHub Pages (branch `main`, pasta raiz). Não depende de servidor nem de CDN.
